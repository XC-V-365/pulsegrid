# Effects Labs (in-app)

Master-bus FX chain (Web Audio):

| Module | Controls |
|--------|----------|
| Compressor | threshold, ratio |
| Filter | lowpass freq, Q |
| Saturation | waveshaper drive |
| Delay | time, feedback, mix |
| Reverb | IR room, mix |
| Limiter | soft ceiling |

State is stored in JSON v6 `fx` object. Reset restores defaults.
