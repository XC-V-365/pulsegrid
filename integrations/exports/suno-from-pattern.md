# Suno export from PulseGrid

Use **Connections → Suno** in the app, or paste the generated package into Suno **Custom Mode**.

Template variables filled by the sequencer:

- `{title}` — e.g. PulseGrid Midnight Grid
- `{bpm}` — transport BPM
- `{density}` — low / medium / high from active step count
- `{swing}` — swing percent
- `{tags}` — from pattern character (four-on-floor, sparse, hat-driven…)
