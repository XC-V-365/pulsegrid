# PulseGrid × Claude (Code · Opus 5.5 · Fable 5.1)

Paste-ready briefs and agent rules for **Claude Code**, **Claude Opus 5.5**, and **Claude Fable 5.1**, plus **Composio** tool routing.

> Model names follow this project’s labeling. Point Claude Code / API at the model your account actually exposes (e.g. latest Opus / Sonnet). Packs stay valid as **system + user** prompt shapes.

## Files

| Path | Use |
|------|-----|
| `CLAUDE_CODE.md` | Claude Code project instructions (`CLAUDE.md` style) |
| `OPUS_5_5.md` | Deep engineering / architecture (Opus 5.5) |
| `FABLE_5_1.md` | Narrative / brand / music storytelling (Fable 5.1) |
| `SYSTEM_RULES.md` | Shared constitution (anti-slop, matrices, authorized RE only) |
| `../composio/` | Multi-app agent tools |
| `../exports/claude-code-brief.md` | Short paste from sequencer stats |

## Quick flow

1. Open PulseGrid → pattern → **Claude Code** / **Opus** / **Fable** / **Composio** chips  
2. Paste into Claude Code chat or Claude.ai project knowledge  
3. For multi-app publish: Composio bundle → connected GitHub/Notion/etc.
