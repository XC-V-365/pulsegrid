# PulseGrid — Licence (editable)

See Admin → Licence for the live clause. Default below.

## ALL LICENCES

The project owner may set and change licensing for software, patterns, generated packages, documentation, and brand assets.

- **Default scaffold (until changed):** MIT for application source in this repository.
- **Operator override:** Admin panel can replace this text in-product without redeploying (demo: localStorage; production: database).
- **User content:** Patterns and exports belong to the creating account subject to platform terms.
- **Third-party AI (Suno, Udio, etc.):** User must comply with those services’ terms.
- **Donations / sponsorships:** Purchase a limited **7-day generation window** only; they do not sell ownership of the platform.
- **Admins:** Owner email + up to 12 configured admin emails have full access and may revise this clause.

## Free trial

Everyone who is not an admin gets **very limited** free-trial access (see `saas/access-config.js`).

## Generation

**7-day generation access is only available to donators and sponsors** (and admins), not to free trial users.
